How to use it

Every lesson's code also lives in the repo, ready to run.

  1. Do Lesson 0 to install Python and VS Code.
  2. Download the code from GitHub (Code → Download ZIP) and open the folder in VS Code.
  3. For each lesson: read it here, run example.py, write your answer in exercise.py, and only then compare with solution.py.
  4. Run a file from the VS Code terminal with python 02-strings/example.py (on Windows, py works too).
