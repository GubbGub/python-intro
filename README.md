# Python Intro

A small, no-fluff introduction to Python, built from my own study notes.

**Take the course: [gubbgub.github.io/python-intro](https://gubbgub.github.io/python-intro/)**

Every lesson follows one rule: **one idea, one example, one exercise.** Read the idea, run the example, then close the example and write the exercise yourself before you look at the solution.

## Companion textbook

**[Introduction to Python Programming](https://openstax.org/details/books/introduction-python-programming)** from OpenStax is free and open, and it's the textbook my dual-enrollment Python course was taught from. It goes deeper than these lessons, and its built-in code runner lets you practice in the browser. Each lesson here ends with the matching sections to read.

## How to use this

1. Do [Lesson 0](00-setup/) to install Python and VS Code.
2. Clone this repo (or click **Code → Download ZIP**) and open the folder in VS Code.
3. For each lesson:
   - read its `README.md`
   - run `example.py`
   - write your answer in `exercise.py`
   - check it against `solution.py` only after you've tried

Run any file from the VS Code terminal:

```bash
python 02-strings/example.py      # on Windows you can also use: py 02-strings/example.py
```

## Editing the course

The lesson folders are the single source of truth. The website (`index.html`) reads `lessons.js`, which `build.py` generates from every lesson's `README.md`.

```bash
pip install markdown pygments   # once
python build.py                 # after editing any lesson README
./publish.sh "what changed"     # rebuild, commit and push in one step
```
