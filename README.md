# Python Intro

A small, no-fluff introduction to Python, built from my own study notes.

Every lesson follows one rule: **one idea, one example, one exercise.** Read the idea, run the example, then close the example and write the exercise yourself before you look at the solution.

## How to use this

1. Do [Lesson 0](00-setup/) to install Python and VS Code.
2. Clone this repo (or click **Code → Download ZIP**) and open the folder in VS Code.
3. For each lesson:
   - read its `README.md`
   - run `example.py`
   - write your answer in `exercise.py`
   - check it against `solution.py` only after you've tried

Run any file from the VS Code terminal:

```bash
python 02-strings/example.py      # on Windows you can also use: py 02-strings/example.py
```
